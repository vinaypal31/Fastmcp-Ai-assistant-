# 🚀 FastMCP AI Automation Assistant

A powerful AI automation assistant built using FastMCP and LangChain that can:

- Perform real-time web search
- Send real emails via SMTP
- Summarize YouTube videos
- Play and control YouTube songs
- Manage GitHub repositories
- Automate browser & system tasks
- Take screenshots
- Control system volume

---

## 🛠 Tech Stack

- Python
- FastMCP
- LangChain Community
- Google Serper API
- SMTP (Gmail)
- GitHub REST API
- PyAutoGUI
- PyWhatKit

---

## ✨ Features

### 🔎 Web Search
Performs real-time factual search using Google Serper API.

### 📧 Email Automation
Send real emails using Gmail SMTP.

### 🎥 YouTube Tools
- Extract and summarize transcripts
- Play songs
- Pause/Resume songs
- Play songs by singer
- Open next related song

### 🐙 GitHub Automation
- List repositories
- Create repository
- Create file in repo
- Read file from repo

### 🌐 Browser Automation
- Open any website

### 🖥 System Automation
- Take screenshot
- Increase volume
- Decrease volume
